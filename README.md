# ЦОР «Что общего у разных растений? Части растения»

Окружающий мир, 1 класс, УМК «Школа России» (А. А. Плешаков).

Откройте `index.html` в браузере — работает офлайн, без интернета.

- Этап 1 «Сообщение нового знания»: экраны 1–3 (загадка, изучение частей растения, опорная схема).
- Этап 2 «Первичное закрепление»: экраны 4–6 («Подпиши растение», «Что мы едим?», «Найди ошибки»).

Управление: кнопки «Назад/Далее» внизу или стрелки ←/→; **T** (или нажатие на номер экрана) — панель учителя;
**F** — во весь экран.
